# 조제 화면을 남에게 보여주기

## 1. 같은 와이파이에 있는 사람에게 (가장 간단)

발표장·강의실처럼 **같은 네트워크**에 있으면 이것만으로 됩니다.

```bash
cd ~/omx_pill_project/web
python app.py --real --host 0.0.0.0
```

`--host 0.0.0.0` 이 핵심입니다. 기본값(127.0.0.1)은 이 컴퓨터에서만 열립니다.

그러면 다른 사람은 브라우저에 이 주소를 칩니다.

```
http://192.168.129.41:8000
```

**주소는 바뀝니다.** 켜기 전에 확인하십시오.

```bash
hostname -I | awk '{print "http://" $1 ":8000"}'
```

방화벽이 막으면 한 번만 열어 주면 됩니다.

```bash
sudo ufw allow 8000/tcp
```

## 2. 다른 곳에 있는 사람에게 (인터넷)

같은 와이파이가 아니면 터널이 필요합니다.

```bash
# 설치 (한 번만)
sudo snap install ngrok

# 실행 — 서버를 먼저 켜 두고
ngrok http 8000
```

`https://xxxx.ngrok-free.app` 같은 주소가 나오고, 그 링크로 누구나 접속합니다.

**주의**: 이 링크는 인터넷 전체에 열립니다. 아는 사람에게만 알려주고, 발표가
끝나면 `Ctrl+C` 로 닫으십시오. 조제 버튼을 누르면 **실제 로봇이 움직입니다.**

## 3. 화면만 보여주기 (로봇은 안 움직이게)

발표 자료로만 보여줄 때는 시뮬레이션 모드로 켭니다.

```bash
python app.py --host 0.0.0.0
```

`--real` 을 빼면 로봇 없이 흐름만 재현합니다. 남이 실수로 눌러도 안전합니다.

## 자주 쓰는 조합

| 상황 | 명령 |
|---|---|
| 내 컴퓨터에서만 보며 시연 | `python app.py --real` |
| 같은 와이파이 사람들에게 공개 | `python app.py --real --host 0.0.0.0` |
| 로봇 없이 화면만 공유 | `python app.py --host 0.0.0.0` |
| 정책이 본 화면 녹화까지 | `REC=1 python app.py --real --host 0.0.0.0` |
| 다른 포트로 | `python app.py --real --port 8080` |
