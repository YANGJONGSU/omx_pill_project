# OMX 알약 자동 조제 — 발표 자료

**AI 기반 대학병원 환자 안내 및 약국 자동 조제 로봇 시스템** / OMX 조제 파트

## 세 폴더

| 폴더 | 무엇 | 언제 |
|---|---|---|
| **`01_핵심/`** | 발표에 실제로 쓸 것 — 그림 5장, 영상 2개, 발표 순서와 근거 | **먼저 보십시오** |
| `03_준비과정/` | **데이터를 어떻게 만들었나** — 배치 설계, 촬영 계획, 설계 문서 | 과정을 보일 때 |
| `02_전체/` | 근거 원본 — 실험 기록 19개, 지표 10개, 실기 궤적 10개 | 질문이 들어왔을 때 |

## 이 프로젝트의 이야기

여러 색이 섞인 트레이에서 **처방된 색만 순서대로 골라 약통에 담는** 로봇을
모방학습으로 만들었습니다.

```
데이터 설계    손으로는 무작위를 못 만든다 → 난수 배치표 + 화면 오버레이
목표 조건화    다섯 번 실패 → 여섯 번째에 해결
실행 구조      정책이 아니라 여기가 문제였다 (4건)
```

**모델을 바꾸기 전에 데이터를 바꿨습니다.** 성능을 가장 크게 움직인 것은
학습 설정이 아니라 촬영 설계였습니다 — 그 과정이 `03_준비과정/` 에 있습니다.

| 정책 | 실기 |
|---|---|
| 좌표 조건화 (`act_xy_224`) | 3색 연속 성공, 91초 |
| 원-핫 + FiLM (`act_film_224`) | 3색 연속 성공, 166초 |
| 색별 정책 3개 | 색별 단독 동작 확인 |
