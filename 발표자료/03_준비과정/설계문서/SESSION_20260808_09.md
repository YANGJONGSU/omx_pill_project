## 3. 정정한 것 (발표에서 뺐음)

**"증강이 색 구분을 만들었다"** 는 통제 비교를 통과하지 못했다.

```
10K 같은 조건 (맨바닥·배치8·같은 데이터, 증강만 다름)
  증강 ON   1.30배
  증강 OFF  1.62배   ← 오히려 OFF 가 높다
```

기존 결론은 조건이 여러 개(파인튜닝→맨바닥, 10K→40K, 증강 OFF→ON) 동시에 바뀐
실행들을 비교한 것이었다. 실기 개선은 **맨바닥 학습 + 스텝 증가** 쪽일 가능성이 크다.
