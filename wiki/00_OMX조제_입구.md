## 학습 방식 두 가지

같은 ACT 를 두 가지 방식으로 썼다. **"어느 알약을 집을지"를 모델에게 어떻게 알려주느냐**가 다르다.

| | **A. 색별 정책 3개** | **B. 원-핫 단일 정책** |
| --- | --- | --- |
| 정책 개수 | 3개 (빨강·초록·노랑) | 1개 |
| 목표 지정 | 정책을 갈아끼움 — **입력 없음** | 3차원 원-핫 입력 + FiLM |
| 자기색 대비 | **3.26 ~ 5.45** | 1.00 ~ 1.22 (기준선 1.02) |
| 실기 | **작동한다 — 집어서 담는다** | 지시를 무시하고 아무거나 집는다 |
| 시연 | ✅ **이걸로 한다** | ❌ |
| 확장성 | 색 늘리면 학습을 하나 더 | 데이터만 추가하면 됨 |

**A 는 되고 B 는 안 된다.** B 가 프로젝트 설계 원안이었고 확장성이 좋지만,
모델이 목표를 읽지 않고도 손실을 줄이는 통로를 계속 찾아냈다.
자세한 경위는 [[OMX-조제-트러블슈팅]] A-2 · A-3.

### 그 밖에

| | 상태 |
| --- | --- |
| 지각·위치잡기 | 처음부터 됐다. 화면만으로 목표 위치를 찾는다 (화면 기여 +0.76) |
| 담고 나서 멈추기 | 정지 시연 32개를 촬영해 대응 중 |

시연은 **A 방식**으로 한다. 웹에서 처방을 넣으면 서버가 색마다 `pick()` 을
한 번씩 호출한다 — 모델은 "하나 집기"만 알고, 순서는 서버가 처리한다.

## 조제 흐름

```
환자 정보 입력  →  병명 선택  →  처방(색 조합) 결정
                                      ↓
                        서버가 색 순서대로 pick() 호출
                                      ↓
        빨강 정책으로 빨강 집기  →  노랑 정책으로 노랑 집기  →  완료
```

### 처방표 (정형외과 4종)

| 코드 | 병명 | 조합 | 비고 |
| --- | --- | --- | --- |
| OS-01 | 단순 타박상 | 빨강 | 소염진통제만 |
| OS-02 | 급성 요통 | 빨강 → 초록 | 소염진통제는 위를 자극해 위장보호제를 함께 |
| OS-03 | 근육 염좌 | 빨강 → 노랑 | 근육 경직이 동반되면 근이완제 |
| OS-04 | 만성 관절염 | 빨강 → 노랑 → 초록 | 장기 복용이라 위장보호제 필수 |

빨강 = 소염진통제 · 노랑 = 근이완제 · 초록 = 위장보호제

## 이 파트의 핵심 발견 — 지름길 학습

**모델은 시키는 걸 배우지 않고 가장 쉬운 걸 배운다.** 쉬운 길을 막을 때마다
다음으로 쉬운 길을 찾아갔다. 이 프로젝트에서 세 번 반복됐다.

| 막은 것 | 모델이 찾은 다음 길 | 어떻게 알았나 |
| --- | --- | --- |
| 알약 위치를 고르게 뿌림 | 장면 전체를 외움 | 목표를 바꿔도 같은 알약을 집음 (자기색 대비 1.00) |
| 같은 장면에 목표 3개를 붙임 | **CVAE 잠재변수**로 정답을 미리 앎 | 같은 장면에 답이 셋인데 손실이 0.067까지 내려감 |
| 잠재변수를 제거 | (검증 중) | |

> Geirhos et al., *Nature Machine Intelligence* 2020 — **지름길 학습**.
> 논문에서는 별/달 분류에서 별이 항상 오른쪽 위에 있었더니 모양이 아니라 **위치로** 분류했다.
> 우리는 같은 현상이 **로봇 목표 조건화**에서 나타난 사례다.

### 측정 지표 — 자기색 대비

같은 화면에 **목표만 바꿔** 넣고 예측이 얼마나 나빠지는지 잰다.
로봇도, 새 데이터도, 재학습도 필요 없다.

```
자기색 대비 = (틀린 목표를 줬을 때 오차) ÷ (올바른 목표를 줬을 때 오차)
```

| 값 | 뜻 |
| --- | --- |
| 1.02 | **기준선** — 화면을 안 보고 "색 → 그 색의 평균 궤적"만 내는 예측기 |
| 1.00 | 목표를 완전히 무시 |
| 3.26 ~ 5.45 | 색별 정책 3개 (실제로 작동하는 것) |

대부분의 연구는 최종 성공률만 보고한다. 그러면 실패가 "지시를 못 알아들은 것"인지
"손이 서툰 것"인지 구분되지 않는다. **이 지표는 그 둘을 가른다.**

## 실험 기록

| 목표 주입 | 스텝 | 에폭 | 자기색 대비 |
| --- | --- | --- | --- |
| 색별 정책 3개 (목표 없음) | 40K | 9.0 | **3.26 ~ 5.45** |
| 원-핫 토큰 | 40~128K | 2.8~9.0 | 1.00 |
| 원-핫 + FiLM (96개 데이터) | 128K | 8.9 | 1.33 (학습) / **1.03 (미학습)** |
| 원-핫 + FiLM (224개 데이터) | 100K | 3.3 | 1.22 |
| SmolVLA (언어) | 20K | 1.4 | 1.02 |

**1.33 은 대부분 암기였다.** 같은 모델을 한 번도 안 본 장면에서 재보니 1.03 —
기준선과 같았다. 학습 데이터에서 잰 숫자는 그대로 믿으면 안 된다.
