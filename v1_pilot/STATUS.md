
`eval.sh`(lerobot-record)는 구조상 에피소드로 끊고 데이터셋에 저장한다. 그게 필요 없을 때
쓰는 게 `run.sh`(= `run_policy.py`)다.

- **저장하지 않는다.** 데이터셋도, `eval_` 이름 규칙도, 인코딩 대기도 없다
- **시간 상한이 없다.** 켜면 바로 돌고 키를 누를 때까지 멈추지 않는다
- 키: **스페이스** = 홈 복귀 후 정지, **s/p** = 재개/그 자리 정지, **ESC 또는 q** = 홈 복귀 후 종료
- 홈 자세 = 노랑 30개의 에피소드 시작 자세 중앙값
  `[0.34, -61.34, 55.02, 44.13, 0.93, 59.72]` (관절별 std 2.5 이내로 일관). `--set-home`으로
  바꾸면 `home_pose.json`에 저장되고 이후 그 값을 쓴다
- 홈 복귀는 현재 자세에서 smoothstep 보간으로 이동한다(최소 3초, 25단위/초 상한). 서보가
  최대 속도로 튀지 않는다
- 종료 시 **토크는 켠 채로** 둔다(팔이 주저앉지 않게). 힘을 빼려면 `--relax-on-exit`
- wrist USB가 빠져도 죽지 않는다 — 관측 3회 연속 실패면 홈으로 보내고 정리하고 끝낸다
- 첫 추론 0.4초 지연은 연결 전에 가짜 관측으로 미리 소진한다(워밍업). 실제 루프는
  스텝당 3ms, 청크 재예측 시 15~20ms로 30Hz(33ms) 예산 안에 든다
